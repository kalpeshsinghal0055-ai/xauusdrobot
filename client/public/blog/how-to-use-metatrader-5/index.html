How to Use MetaTrader 5: The Complete First-Week Walkthrough

By the XAUUSD Robot Team · Updated August 2026

TL;DR MetaTrader 5 has four skills worth learning in week one: (1) setup — install from your broker, log in with the server they emailed; (2) charts — open XAUUSD from Market Watch, switch timeframes, add a moving average; (3) orders — always via the order window with a stop-loss typed in before clicking Buy/Sell; (4) automation — drop an EA in the Experts folder, enable Algo Trading, test on demo. Everything else in the platform is optional; these four are the job.

Step 1: install and log in (10 minutes)

  1. Download MT5 from your broker, not metatrader.com — broker builds come pre-pointed at their servers. Every regulated broker links it under Platforms.
  2. Install, open, then File → Login to Trade Account: the login number, password and server name are in the email your broker sent when you opened the account (demo or live).
  3. Check the bottom-right corner: a green connection number means you're in; "Invalid account" almost always means the wrong server was selected, not the wrong password.

Step 2: read the platform in one tour

PanelWhat it's for
Market Watch (Ctrl+M)Instrument list with live bid/ask — right-click → Symbols to find XAUUSD if hidden
ChartDrag a symbol from Market Watch onto it; M1–MN buttons switch timeframes
Navigator (Ctrl+N)Your accounts, indicators and Expert Advisors live here
Toolbox (Ctrl+T)Open trades, order history, alerts, and the EA logs (Experts tab)

Two chart habits worth building immediately: trade from the 1H/4H timeframes (minute charts are noise — see the indicator guide), and add one moving average (Insert → Indicators → Trend) so the trend question always has an answer on screen.

Step 3: place an order properly (the part that matters)

  1. Press F9 (or right-click chart → Trading → New Order).
  2. Set Volume in lots — 0.01 to start, sized by risk with the lot calculator, never by feel.
  3. Type the Stop Loss and Take Profit prices BEFORE clicking Buy or Sell. This is the whole discipline in one habit — an order without a stop is a promise to improvise later.
  4. Click Buy or Sell; the position appears in the Toolbox. Modify SL/TP anytime by dragging the lines on the chart or right-clicking the position.

Gold-specific note: place stops beyond obvious levels with ATR-sized buffers — XAUUSD's wick-hunts take out line-thin stops daily. And know your two costs before sizing anything: the spread and slippage.

Step 4: the Strategy Tester — MT5's best feature

View → Strategy Tester (Ctrl+R) lets you replay any EA or indicator over years of history before a cent goes live. Choose the EA, XAUUSD, "Every tick based on real ticks" modelling, a realistic spread — then read the report's maximal drawdown before its profit line. The honest method is in how to backtest properly; this tester is the main reason serious EA users pick MT5 over MT4.

Step 5: install and run an Expert Advisor

  1. File → Open Data Folder → MQL5 → Experts — copy the EA file (.ex5) here.
  2. Restart MT5 (or refresh Navigator). The EA appears under Expert Advisors.
  3. Drag it onto the XAUUSD chart, allow live trading in the dialog, and click the Algo Trading toolbar button so it turns green.
  4. A smiley hat icon on the chart's top-right = running. Check the Experts tab in Toolbox for its logs.
  5. Demo first, always — then the full robot setup guide covers settings and the VPS step for 24/5 running.

The settings that save beginners pain

  • Tools → Options → Expert Advisors: "Allow algorithmic trading" must be ticked or every EA silently does nothing.
  • One-Click Trading off until you're experienced — it skips the order window, which means skipping the stop-loss habit.
  • Charts → Show trade levels on — seeing your SL/TP lines on the chart keeps risk visible.
  • Notifications: Toolbox → Alerts, or link the MT5 mobile app (same login) to monitor positions from your phone — monitoring, not managing; the desktop/VPS runs the show.

Questions we get

How do I start using MetaTrader 5?

Broker's MT5 build → File → Login with the emailed server details → drag XAUUSD onto a chart.

Is MetaTrader 5 free?

Yes — free from any broker; you only pay trading costs.

How do I place an order with stop-loss in MT5?

F9 → set lots → type SL/TP first → then Buy/Sell. Adjust by dragging chart lines.

Where do I put EA files in MetaTrader 5?

File → Open Data Folder → MQL5 → Experts, then drag from Navigator + enable Algo Trading.

Why is my EA not trading in MT5?

Algo Trading button off, options unticked, licence/settings, or market closed — check the Experts log.

Can I use MT5 on my phone?

Yes for monitoring/manual trades — but EAs need the desktop terminal or a VPS running.

The verdict

MetaTrader 5 looks intimidating and is actually four learnable skills: log in correctly, read the chart, order with a stop typed first, and let the tester prove things before money does. Master those on demo in a week and the platform disappears into the background — which is exactly where a platform belongs, whether your hands or a well-tested robot are doing the clicking.
